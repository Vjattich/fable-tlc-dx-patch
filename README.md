# Fable-tlc-dx-patch
This fast patch enable alt+enter hotkey for Fable: The Lost Chapter and make it normally switchable; without it, you need some soft to run it in window and make it available to capture to stream for example.

# usage
Build\download from releases d3d9.ddl and add it in game folder. If u need settings copy [d3d9proxy.ini](d3d9proxy.ini). 

# settings
all settings in [d3d9proxy.ini](d3d9proxy.ini) 

# build
run [build.bat](build.bat) on windows. If u run build.bat -log it will build log output for debugging 

Need python and ziglang for it
